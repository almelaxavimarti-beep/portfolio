Estas son las herramientas que uso en clase para hacer mis páginas y mis programas.

Editor de código

Uso Visual Studio Code (se abre en otra pestaña). Me gusta porque colorea el código, autocompleta las etiquetas y tiene un terminal integrado.

Atajos que más uso:

  • Ctrl + S: guardar el archivo.
  • Ctrl + Ñ: abrir el terminal.
  • ! + Tab: crear la estructura básica de un HTML.

Control de versiones

Guardo mi trabajo con Git y lo publico en mi perfil de GitHub (se abre en otra pestaña). Los comandos que más uso son:

  1. git add . para preparar los cambios.
  2. git commit -m "mensaje" para guardarlos con una descripción.
  3. git push para subirlos a GitHub.

Navegador

Abro mis páginas en el navegador para comprobar cómo se ven. Con F12 abro las herramientas de desarrollador y reviso el HTML.

Sistema operativo

Gracias a lo que aprendí en TSMR me muevo bien por el terminal de Linux: ls, cd, mkdir, grep…
