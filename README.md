# Portfolio de Xavi Almela

Portfolio personal de **Xavi Almela Marti**, estudiante de 1.º de Desarrollo de Aplicaciones Multiplataforma (DAM) en Florida Campus Alzira.
Es la **versión 1** (etiqueta `v1`): un sitio de 5 páginas en HTML semántico, válido y accesible, sin CSS todavía. En el segundo trimestre le daré diseño.

🌐 **Ver publicado:** https://almelaxavimarti-beep.github.io/portfolio/

## Páginas

| Página | Contenido |
|---|---|
| [`index.html`](index.html) | Presentación con avatar, quién soy y qué busco, 3 proyectos destacados y el aside «Ahora estoy aprendiendo» |
| [`sobre-mi.html`](sobre-mi.html) | Trayectoria, aficiones y objetivos, con índice de anclas y «Volver arriba» |
| [`proyectos.html`](proyectos.html) | 6 proyectos del trimestre, cada uno en un `article` con captura, descripción y lo que aprendí |
| [`cv.html`](cv.html) | Tablas de formación y competencias, e idiomas |
| [`contacto.html`](contacto.html) | Formulario validado con `fieldset` y `label`, enlace `mailto:` y enlace a GitHub |
| [`entorno.html`](entorno.html) | Mi entorno de trabajo (Actividad 5) |

## Tecnologías

- **HTML5** semántico: `header`, `nav`, `main`, `section`, `article`, `aside`, `figure` y `footer`.
- Accesibilidad: enlace «Saltar al contenido», `aria-current="page"`, textos alternativos y tablas con `caption` y `scope`.
- Validación con el **W3C Markup Validator**.
- **Git** y **GitHub** para el historial, y **GitHub Pages** para publicarlo.
- Editado con **Visual Studio Code** y la extensión Live Server.

## Uso de inteligencia artificial

He usado un asistente de IA (Claude) como apoyo en este portfolio: para revisar qué pedía el enunciado, proponer la estructura semántica de las páginas, redactar un primer borrador de algunos textos y generar las capturas de consola de SmartCalc y RoverLab.
Yo he revisado y adaptado los textos con mis datos, he comprobado que todo valida en el W3C y he hecho los commits y la publicación.
Los programas SmartCalc y RoverLab son mis propias entregas de Programación.
